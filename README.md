# Su-30VXN Gandiva

This mod brings the Su-30VXN into Nuclear Option.

# Installation
1. Have Blueprinter installed. Can be downloaded at https://github.com/nikkorap/NOBlueprinter-Releases
2. Download the latest version from the Releases tab.
3. Place the .dll file inside your `NuclearOption/BepInEx/plugins` folder with Blueprinter installed.
